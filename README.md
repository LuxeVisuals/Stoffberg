# Hoërskool Stoffberg — Website Redesign

Static, GitHub-ready redesign with a yellowish-gold and deep-green Stoffberg-inspired visual identity.

Features:
- Responsive mobile/desktop layout
- Animated scroll reveals
- Mobile navigation
- Professional hero sections and cards
- Local image placeholders
- Policy/document placeholders
- Staff, academic, sport and culture sections
- Contact form UI
- Back-to-top button

## Replace images
The site currently uses CSS/SVG placeholders so it works immediately without external image files. Replace each `.placeholder` block with an `<img>` when the final school photos are available.

## Deploy
Upload the entire folder to GitHub and enable GitHub Pages. `index.html` is the homepage.
